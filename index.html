📖 Available Helper Functions

            
        

        

            

                
TreeNode(val, left=None, right=None)

                
Standard binary tree node. Fields: val, left, right.

            

            

                
root

                
Pre-built from your tree input above. Use this variable directly in your solution.

            

            

            

                
build_tree(arr)

                
Builds a tree from a LeetCode-style list. None = no node.

            

            

                
build_tree_dash(arr)

                
Builds a tree from a list where -1 = no node.

            

            

            

                
print_tree(root)

                
Pretty-prints the tree structure with branch lines to the console.

            

            

                
tree_to_list(root)

                
Serializes tree back to a LeetCode-style list (level-order).

            

            

            

                
inorder(root)

                
Returns in-order traversal as a list: Left → Root → Right.

            

            

                
preorder(root)

                
Returns pre-order traversal as a list: Root → Left → Right.

            

            

                
postorder(root)

                
Returns post-order traversal as a list: Left → Right → Root.

            

            

                
level_order(root)

                
Returns level-order traversal as a list of lists.
